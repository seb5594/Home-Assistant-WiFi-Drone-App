# Changelog

## 0.3.2

- Log JieLi camera replies and packet counts per UDP listener when video times out.

## 0.3.1

- Support the Sky Cam CTP access version observed in a hardware capture.

## 0.3.0

- Receive the H.264 camera stream from Lewei / WiFi-720P toys over TCP and show it as MJPEG.

## 0.2.0

- Connect to a drone access point using an isolated WiFi App Helper radio lease.
- Support open networks and WPA2-Personal with a dedicated DHCP camera route.
- Add KY UFO RTSP with video heartbeats and JieLi/HF CTP with JPEG reception.
- Show the WiFi connection stage in the web view.

## 0.1.0

- Added a local bridge for RTSP and HTTP(S) camera sources.
- Added live MJPEG, JPEG snapshots, an authenticated API and a Home Assistant Ingress view.
